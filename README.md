# SHOWUP

A prototype marketplace for booking local home services.

SHOWUP explores a familiar on-demand product model for services such as lawn care, pressure washing, gutter cleaning, and handyman work. The project is structured around three experiences: customers booking services, service providers managing work, and businesses managing operations.

> **Prototype status:** This is an active product prototype built to explore marketplace workflows and user experience. It is not presented as a production-ready platform.

## What I built

- Customer flows for browsing, booking, tracking, orders, gifting, and group use
- Provider application and dashboard flows
- Business-facing operational screens for managing services, hours, promotions, and payouts
- A browser-side identity onboarding concept with consent and safety steps
- A multi-surface product structure designed around a real service marketplace workflow

## Why this project

I wanted to explore the operational complexity behind an on-demand service marketplace rather than build another isolated demo. The project combines product design, workflow thinking, user-state management, and practical business requirements.

## Project structure

**Customer** — discovery, booking, tracking, orders, passes, gifts, and group workflows.

**Service provider** — application, dashboard, offers, earnings, and ratings.

**Business** — operational views for service management, availability, promotions, and payouts.

## Technical note

The repository is being documented and cleaned up as the prototype evolves. Some workflows are simulations intended to demonstrate product behavior rather than live integrations.

## Portfolio context

SHOWUP is one example of how I approach a problem: start with the user and operating model, map the major workflows, and then build a working prototype that can be tested and improved.
